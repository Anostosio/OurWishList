# Автозаполнение по ссылкам магазинов

Дата проверки: 8 сентября 2026 года.

Проверка считается полной, только если магазин вернул название, изображение и цену. Частичное заполнение оставляет доступные поля редактируемыми и не мешает сохранить желание.

| Магазин | Название | Фото | Цена | Итог |
|---|---:|---:|---:|---|
| Wildberries | да | да | да | полное |
| Poizon | да | да | да | полное |
| Яндекс Маркет | да | да | да | полное через резервный Bright Data collector; месячный бесплатный лимит |
| Ozon | да | да | да | полное через резервный официальный scraper API; месячный бесплатный лимит |
| DNS | из адреса | нет | нет | частичное: витрина блокирует серверный запрос |
| М.Видео | да | да | да | полное через резервный Bright Data collector; месячный бесплатный лимит |
| Lamoda | из адреса | нет | нет | частичное: вместо товара серверу отдаётся заглушка |
| ЛЭТУАЛЬ | да | да | да | полное через резервный Bright Data collector; месячный бесплатный лимит |
| Спортмастер | только общее | нет | нет | частичное: витрина не отвечает за отведённое время |

Команда для повторной проверки:

```powershell
python scripts/audit_metadata.py
```

Для Ozon подключён готовый Bright Data scraper, а для Яндекс Маркета, М.Видео и ЛЭТУАЛЬ — отдельные collectors. Они включаются как резерв после прямого парсинга, кроме Яндекс Маркета, который всегда отдаёт серверу CAPTCHA. Аккаунт работает без платёжного способа на ежемесячных бесплатных кредитах; после исчерпания лимита приложение сохраняет возможность ручного заполнения. Прямой парсинг остаётся первым способом, поэтому ссылки читаемых магазинов внешнему сервису не передаются и бесплатный лимит не расходуется.
