# Автозаполнение по ссылкам магазинов

Дата проверки: 8 сентября 2026 года.

Проверка считается полной, только если магазин вернул название, изображение и цену. Частичное заполнение оставляет доступные поля редактируемыми и не мешает сохранить желание.

| Магазин | Название | Фото | Цена | Итог |
|---|---:|---:|---:|---|
| Wildberries | да | да | да | полное |
| Poizon | да | да | да | полное |
| Яндекс Маркет | да | нет | нет | частичное: витрина блокирует серверный запрос |
| Ozon | только общее | нет | нет | частичное: короткая ссылка скрывает товар за защитой витрины |
| DNS | из адреса | нет | нет | частичное: витрина блокирует серверный запрос |
| М.Видео | только общее | нет | нет | частичное: витрина блокирует серверный запрос |
| Lamoda | из адреса | нет | нет | частичное: вместо товара серверу отдаётся заглушка |
| ЛЭТУАЛЬ | из адреса | да | нет | частичное |
| Спортмастер | только общее | нет | нет | частичное: витрина не отвечает за отведённое время |

Команда для повторной проверки:

```powershell
python scripts/audit_metadata.py
```

Для стабильной полной поддержки защищённых витрин нужен подключаемый сервис браузерного извлечения с собственным API-ключом. Прямой парсинг остаётся первым способом, а такой сервис должен вызываться только при неполном результате. Это уменьшает стоимость и не передаёт внешнему сервису ссылки магазинов, которые уже читаются напрямую.
