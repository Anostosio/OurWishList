# Наш вишлист 💛

Приватный Telegram-бот для пары, версия 0.2. Python 3.12+, SQLite, без внешних библиотек.

## Что уже есть

- Пара по одноразовой ссылке-приглашению (24 часа, максимум два участника).
- Списки «Моё», «Партнёра», «Наше» и архив «Сбылось».
- Сохранение ссылки и комментария, получение названия, фотографии и цены из Open Graph / JSON-LD.
- Если магазин недоступен, желание остаётся в базе и заполняется вручную.
- Желания обычным текстом без ссылки, изменение названия, цены и деталей.
- Три приоритета, перенос в общий список, архивирование и восстановление.
- Скрытое бронирование личного желания партнёра. Получателю не показывается даже факт брони.
- Защита от повторной ссылки в своём активном списке, постраничный просмотр.
- `/export` — текстовая JSON-выгрузка своих желаний без секретных броней.
- Галерея фото прямо в чате, кнопки перелистывания и открытие полной карточки.
- Поиск по названию, комментарию, размеру и цвету; фильтры по категории и бюджету, порядок по приоритету или дате.
- Собственные фотографии: новая хотелка из фото с подписью, замена и удаление фото в карточке.
- Отдельные поля размера, цвета, категории; «Именно это / Можно аналог / Вариант не уточнён».
- Проверка цены по запросу, без перезаписи ваших комментариев, фотографии и названия.

## Новые сценарии

- `/gallery` → выберите список → листайте стрелками → «Открыть карточку».
- «Фильтры» → категория, поиск или бюджет. Бюджет вводится с валютой: `2000 UAH`, `50 EUR`, `100 USD`. Разные валюты не сравниваются; неизвестные и диапазонные цены исключаются из бюджетной подборки. Фильтры личные, сохраняются между перезапусками и действуют во всех ваших списках; «Сбросить всё» возвращает полный список.
- Отправьте фото с подписью: появится новая хотелка. В подписи можно указать одну ссылку. Для замены фото у существующей хотелки сначала нажмите «Фото» в её карточке.
- «Изменить» → размер, цвет, комментарий, категория или допустимость аналога. Если выбрано «Именно это», партнёр увидит это прямо в карточке.
- «Изменить» → «Проверить цену в магазине»: сохраняется новая найденная цена и дата проверки. Если магазин не отвечает, прежняя цена остаётся. Размер и комплектацию всё равно нужно сверить в магазине.

Это галерея сообщений Telegram. Дополнительно доступен базовый Mini App с карточной сеткой.

Как использовать Mini App:

- настройте `WEBAPP_URL` в `.env` на страницу вашего Mini App.
- для Vercel: деплойте только UI из `wishlist/miniapp/index.html` (файл в репозитории).
- добавьте в `.env` `WEBAPP_API_BASE` — адрес API вашего локального `miniapp_server` (например `https://xxxxx.loca.lt`).
- отправляйте в бот `/app` или нажимайте кнопку `📱 Mini App` в меню.
- бот создаёт одноразовый `session` и добавляет его в ссылку.

Пример локальной связки с public API через localtunnel:
- `npx -y localtunnel --port 8765` → получили адрес API `https://*.loca.lt`
- `npx -y localtunnel --port 8765 --subdomain my-wishlist-api` (если хотите стабильнее при перезапусках)
- в `.env`:  
  `WEBAPP_URL=https://<ваш-project>.vercel.app`  
  `WEBAPP_API_BASE=https://<api>.loca.lt`  
  `WEBAPP_BIND=127.0.0.1`  
  `WEBAPP_PORT=8765`
- перезапустите `wishlist.miniapp_server` и бот.

Если мини‑приложение открытo через Telegram из Vercel, оно делает API‑запросы на `WEBAPP_API_BASE`.

### Быстрый запуск на Vercel (когда есть вход в аккаунт)

```powershell
npx -y vercel login
npx -y vercel deploy --confirm --prod
```

Минимальный запуск локально (без Vercel):
- `python -m wishlist.miniapp_server`
- `WEBAPP_URL=http://127.0.0.1:8765`
- `WEBAPP_API_BASE=http://127.0.0.1:8765`
- перезапуск бота.

## Запуск на Windows

1. Создайте бота через официальный [@BotFather](https://t.me/BotFather): `/newbot`.
2. Откройте подготовленный `.env` и вставьте токен после `TELEGRAM_BOT_TOKEN=`. Если файла нет, скопируйте `.env.example`. Не публикуйте этот файл и не присылайте токен в переписку.
3. В PowerShell из папки проекта:

```powershell
# Заполните .env в редакторе, затем:
python -m wishlist.bot
```

Если `.env` уже заполнен, не копируйте пример повторно. Завершение: Ctrl+C.

Откройте бота в Telegram, нажмите Start. Создайте приглашение и передайте партнёру. После подключения личные желания обоих видны друг другу: «Моё» означает получателя подарка, а не секретный список.

Отправьте ссылку и необязательную заметку в одном сообщении. Или просто напишите «Мастер-класс по керамике вдвоём». Выберите «Для нас», если это общая хотелка.

Бот работает в личных чатах; отдельная группа не нужна. Пока запущен процесс и компьютер не спит, бот доступен. Для постоянной работы нужен отдельный сервер с постоянным диском. Запускайте только один экземпляр на один токен. Ранее установленный webhook необходимо снять перед использованием long polling.

Для фонового перезапуска уже запущенного этим проектом бота:

```powershell
.\scripts\restart.ps1
```

Скрипт проверяет принадлежность сохранённого PID процессу Python с модулем бота, останавливает его, создаёт согласованную резервную копию SQLite и запускает новое скрытое окно процесса. Логи и PID находятся в `data/`. Автозапуск после перезагрузки компьютера не настраивается.

## Проверка

```powershell
python -m unittest discover -s tests -v
```

Автоматические проверки не обращаются к Telegram или магазинам. После подключения токена проверьте вдвоём: приглашение, ссылка с фото, недоступный магазин, редактирование размера, общий список, бронь и неизменность карточки у получателя, архив и восстановление, сохранение после перезапуска.

## Данные и ограничения первой версии

Данные хранятся в `data/wishlist.sqlite3`; путь меняется через `DATABASE_PATH`. Команда `python -m wishlist.backup` создаёт согласованную копию в `data/backups/`. При обновлении схема дополняется автоматически, без удаления существующих желаний и пар. Токен в базе не хранится. Логи не содержат тексты желаний или токен.

- Есть универсальный разбор метаданных; отдельных интеграций с магазинами пока нет. Страницы с JavaScript, защитой или авторизацией могут не распознаться. Размер и цвет уточняйте вручную.
- Цена — сохранённый ориентир, не живая цена; выбор первого предложения магазина может отличаться от выбранного вами варианта.
- Фото магазина отправляется, если Telegram принимает его URL; иначе будет текстовая карточка. Собственные фото хранятся как Telegram file ID. При переходе с фото на желание без фото бот создаёт новое текстовое сообщение, чтобы не показывать чужую фотографию под новым названием.
- Автозагрузка идёт последовательно с сетевыми тайм-аутами. Это достаточно для пары; для большого количества пользователей нужна фоновая очередь.
- Получатель не видит бронь в интерфейсе или экспорте. Администратор компьютера с доступом к SQLite может читать базу.
- Старые сообщения Telegram могут содержать прежние данные; актуальная карточка открывается из списка. Смену пары и удаление аккаунта через интерфейс пока не реализовали.
- Обработка обновлений не является транзакцией с Telegram: сбой процесса в момент ответа может привести к повтору сообщения. Ссылки защищены от повторного добавления; текстовые желания — пока нет.

2. Подключить Mini App к домену и доработать UI‑редактирование прямо в приложении.

## Устройство проекта

- `wishlist/bot.py` — Telegram, карточки и сценарии.
- `wishlist/store.py` — SQLite, доступ, пара, брони и списки.
- `wishlist/catalog.py` — категории и осторожное распознавание цены и валюты.
- `wishlist/backup.py` и `scripts/restart.ps1` — резервная копия и управляемый перезапуск.
- `wishlist/metadata.py` — ограниченная загрузка публичных HTML-страниц и разбор метаданных. Внутренние адреса блокируются, адрес соединения закрепляется после проверки DNS, каждый редирект проверяется заново.
- `tests/test_wishlist.py` — проверки хранения, доступа, скрытых броней, метаданных и сетевых ограничений.
- `tests/test_catalog.py` — миграции, галерея, фото, поиск, валюты, фильтры и обновление цены.
