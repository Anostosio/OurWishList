# Наш вишлист 💛

Приватный Telegram-бот для пары, версия 0.2. Python 3.12+, SQLite, без внешних библиотек.

<!-- Deployment refresh: cloud database environment enabled. -->

## Что уже есть

- Пара по одноразовой ссылке-приглашению (24 часа, максимум два участника).
- Списки «Моё», «Партнёра», «Наше» и архив «Сбылось».
- Сохранение ссылки и комментария, получение названия, фотографии и цены из Open Graph / JSON-LD.
- Если магазин недоступен, желание остаётся в базе и заполняется вручную.
- Желания обычным текстом без ссылки, изменение названия, цены и деталей.
- Три приоритета, перенос в общий список, архивирование и восстановление.

## Карточка желания

Каждая хотелка хранит:

- название;
- ссылку на магазин;
- фотографию;
- цену и дату её последней проверки;
- размер и цвет;
- категорию;
- комментарий;
- приоритет;
- допустимость аналога;
- личный или общий список;
- статус «Сбылось».

## Mini App

В проекте есть Telegram Mini App с карточной витриной. Production-фронтенд и API могут работать на Vercel; при наличии `DATABASE_URL` используется облачный Postgres, а локальный SQLite остаётся режимом разработки.

Для облачного запуска нужны переменные окружения:

- `DATABASE_URL` — строка подключения к Postgres;
- `TELEGRAM_BOT_TOKEN` — токен Telegram-бота;
- `TELEGRAM_BOT_USERNAME` — username бота без `@`;
- `TELEGRAM_WEBHOOK_SECRET` — секрет проверки webhook;
- `WEBAPP_URL` — публичный URL Mini App.

`WEBAPP_API_BASE` для production больше не требуется: Mini App использует same-origin `/api`.
